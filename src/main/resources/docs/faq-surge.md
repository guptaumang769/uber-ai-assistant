# Surge Pricing

When demand for rides in an area is higher than the number of available drivers — during rush hour,
bad weather, or big events — prices go up temporarily. This is called surge pricing, and it encourages
more drivers to get on the road so you can still get a ride.

How it works:
- Surge is shown as a multiplier on the fare estimate (for example, 1.5x or 2.0x). The fare estimate
  you see already includes the current surge, so there are no surprises.
- Surge is specific to a pickup area and changes as demand and driver supply change.
- To pay less, you can wait a few minutes for surge to drop, or move a short distance to a lower-demand
  area before requesting.

The fare estimate endpoint returns the current surge multiplier along with the distance and total fare,
so you always know the price before you request a ride.
